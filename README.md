# NeoLingo — Telegram-бот для изучения японского с ИИ

Бот принимает текст на любом языке и:

1. Переводит его на японский.
2. Делает словарь по смысловым словам (без частиц, глаголы в словарной форме).
3. Для словаря даёт чтение на хирагане.
4. Проводит тест на ввод японских слов.
5. Начисляет звёзды и баллы за правильные ответы.
6. Отправляет аудио с японским текстом.
7. Генерирует вопросы на логику/математику и проверяет ответы.
8. В конце присылает карточку с ёдзидзюкуго.

## Открыть с телефона или другого устройства

### Telegram-бот

1. Установи [Telegram](https://telegram.org/) на телефон или ПК.
2. Найди своего бота по **@username**, который ты задал в [@BotFather](https://t.me/BotFather) при создании токена.
3. Нажми **Start** и отправь любой текст — бот переведёт, протестирует и озвучит.

> Бот работает **в приложении Telegram**, не в браузере. Чтобы он отвечал 24/7, его нужно запустить на ПК или сервере (`python bot.py`).

## Установка (для запуска бота)

```bash
pip install -r requirements.txt
cp .env.example .env
# заполни TELEGRAM_BOT_TOKEN и OPENAI_API_KEY в .env
python bot.py
```

## Results API (синхронизация с лидербордом)

```bash
uvicorn results_api:app --host 0.0.0.0 --port 8000
```

Эндпоинты: `GET /api/health`, `GET /api/results`, `POST /api/results`

## Команды бота

- `/start` или `/help` — инструкция
- `/score` — текущий счёт
- `/reset` — сброс прогресса
- `/health` — проверка OpenAI/прокси

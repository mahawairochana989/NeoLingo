Локальный доступ для других устройств

  1. Запусти сайт на своем ПК: python -m http.server 8891 --bind 0.0.0.0
  2. Узнай свой локальный IP (например, 192.168.1.50).
  3. Отправь ссылку другим в той же сети: http://ТВОЙ_IP:8891.
  4. Если нужно открыть вне локальной сети без сервера, используй туннель (ngrok/localtunnel/cloudflared).
